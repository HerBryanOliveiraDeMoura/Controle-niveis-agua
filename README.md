# 💧 Controle de Níveis de Água

Esse é um projeto que fiz em **Python 🐍** para simular o monitoramento dos níveis de água de um reservatório. 💧

## 📋 Como funciona

O programa verifica cinco níveis de água e exibe uma mensagem de alerta com uma cor diferente para cada situação, utilizando a biblioteca **Colorama 🎨**.

Os níveis são:

- 🔴 **Nível 1 — MUITO BAIXO (CRÍTICO)**
- 🟡 **Nível 2 — BAIXO**
- 🟢 **Nível 3 — MÉDIO**
- 🩵 **Nível 4 — ALTO**
- 🔵 **Nível 5 — MUITO ALTO (ALERTA)**

Se for informado um nível inválido, o programa exibe a mensagem "Nível não encontrado".

## 🧪 Exemplo

```text
Muito baixo (crítico)
Baixo
Médio
Alto
Muito alto (alerta)
```

As mensagens aparecem coloridas no terminal, de acordo com o nível do reservatório.

## 📚 O que pratiquei

Nesse projeto pratiquei:

- 📦 Listas
- 🛠️ Funções com `def`
- ↩️ `return`
- 🔀 Estruturas condicionais
- ❓ `if`, `elif` e `else`
- 🔄 Estrutura de repetição `for`
- 🔢 `range()`
- 🎨 Biblioteca `colorama`
- 🌈 Cores com `Fore`
- ♻️ Restauração de estilo com `Style.RESET_ALL`

## 🎯 Objetivo

Praticar **Python 🐍** utilizando listas, funções, estruturas condicionais e repetição para criar um sistema simples de monitoramento de níveis de água com mensagens coloridas no terminal.
